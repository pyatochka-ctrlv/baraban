# Сорока ТВ — Барабан

Міні-гра для уроку «Думка за 30 секунд» (9–10 років).

1. **Барабан** — дитина крутить три барабани «Де? — Що? — Коли?» (можна замкнути 🔒 сподобане слово) і отримує вигадану ТЕРМІНОВУ НОВИНУ.
2. **У ефір!** — новина й підказки «💡 Думаю → 🔑 Бо → 📸 Наприклад». Дитина нічого не пише: читає підказки й каже думку голосом.

Один файл `index.html`: без мережі, без localStorage, без зовнішніх шрифтів і картинок. Звук вимкнений за замовчуванням (кнопка 🔇/🔊). Клавіші: Пробіл / Enter — крутити, Tab — по кнопках.

Слова барабанів і підказки — масиви `REELS` і `PARTS` на початку скрипта.
